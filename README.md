# Lopet - Mini Social Media

A mini social media platform integrated with LLMs to handle sensitive content reporting.

## API Documentation
Deploy: https://api.nguyenvu.io.vn/swagger-ui.html

## Tech Stack
**Backend:** Spring Boot 4, MySQL, Redis

**Messaging:** Kafka, RabbitMQ

**AI:** Claude API (tool-calling for sensitive content review)

**Infra:** Docker, Caddy (reverse proxy/TLS), VPS deployment
